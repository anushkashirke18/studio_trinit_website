# **App Name**: CampusConnect AI

## Core Features:

- Multi-Role Secure Access: Unified login system for Students and Institutional Administrators with role-based permissions to ensure data security.
- Knowledge Base Manager: Admin portal for schools to upload and manage operational data, exam schedules, and academic timings using an integrated database.
- Smart Assistant Chat: An AI-powered conversational interface for students to inquire about schedules and timings, utilizing a retrieval tool to access current institution data.
- Integrated Schedule View: A clean, non-conversational dashboard for students to see a bird's-eye view of upcoming exams and lecture timings at a glance.
- Dynamic Announcement Feed: A system for administrators to post urgent updates that appear instantly within the chat interface or student dashboard.

## Style Guidelines:

- The palette uses a focused Dark Mode scheme. The primary color is a vibrant Indigo (#887CFA) suggesting intellectual energy, paired with a deep Midnight Blue background (#171520). The accent color is a clear Electric Blue (#4B79FB) used for critical information and action items.
- A professional font pairing of 'Space Grotesk' for structured headers to evoke a technical feel, and 'Inter' (sans-serif) for body text to ensure maximum readability in dense academic schedules.
- Minimalistic, line-art icons that maintain high stroke weight to ensure clarity against the dark background.
- A bento-box inspired layout for the student dashboard that separates the chat interface from the tabular timetable information.
- Smooth, subtle opacity transitions when switching between user roles and localized pulsing indicators in the chat when the assistant is processing data.
